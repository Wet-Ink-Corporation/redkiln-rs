Works today

  • Builds clean on Windows: format, compile, lint and docs all pass.
  • Selects the activities a bug or story needs from a 102-activity catalog, deterministically, and refuses bad pack data at load.
  • Walks both shipped lanes end to end against a fake model (fix 14/14, story 13/13), on real git and real process boundaries.
  • Records state as git trailers plus an append-only log, rebuilds from git, and resumes after a kill.
  • Opens human gates as durable marks; answers arrive later and are voided if the code changed.
  • Rust toolchain adapter runs real cargo build/test/lint/audit/deny. The Node adapter is thin.
  • Launches claude -p locked down and kills the whole process tree on Windows. One live dispatch passed on 21 Sep.
  • All operator verbs exist (run, answer, status, explain, cost, doctor with 43 rules, init, lint).

Not yet

  • No real Claude-driven fix or story lane has run through redkiln run.
  • Adapter pinned to CLI 2.1.278, but 2.1.289 is installed. Least-privilege confinement never tested live.
  • The local branch lacks the remote's CI fixes (including a Linux process-kill bug). CI is green only on the remote head, and 40+ local commits are unpushed.
  • A real lane can't start from a human-written bug report: the first step refuses. Hold-before-spec and shipped-lane run proofs are unbuilt.
  • Acceptance criteria close only by a human "discriminates" answer, never by mutation evidence.
  • Ctrl-C does nothing during a run. status shows one stage for every item.
  • No detection of rewritten history or orphaned anchors. Budget exhaustion isn't wired to a durable stop.

Quality and process, in brief

Code: good to strong. Closed typed errors, fail-closed refusals, effectively no production unwrap or panic, unsafe confined to the containment layer, and ~1,400 tests with positive controls. The weak spots are 25–50% of source lines being dated history comments, a few god modules, policy features built but not wired in, and three confirmed operator-path defects. Everything is proven only against fakes and only on Windows.

Process: honest and self-correcting, but heavy. It records its own false passes, and the adversarial rounds find real bugs. 198 ADRs, 184 decisions and a 50k-line runbook keep the evidence chain intact, but nothing caps scope growth. The records missed the 3–5 Oct remote CI campaign entirely. The operator is now the bottleneck.

How this was checked. I audited a pinned, read-only snapshot (36dd8ac) in a separate worktree, so the live 8i session was never touched. A full build and test ran in an isolated target dir. The 78 test failures all trace to the audit shell: it inherits ANTHROPIC_BASE_URL, which the product refuses by design (61 failures), and a Node fixture was not installed (16). A clean-env re-run went green. 17 survey agents covered vision, plan, 10 code areas, records, traceability, velocity and landing. Two independent skeptics then tried to refute each of 13 headline claims: 7 were confirmed, 6 confirmed with corrections, and none were refuted. A completeness critic added 4 follow-ups.
