TITLE: Make rk-cli doctor use rk-store's credential and network-fs detectors
LABELS: bug
STATUS: untracked

## Finding
Two rk-store helpers written for `doctor` have no production caller: `retention::looks_like_credential` and `conn::looks_like_network_filesystem`. rk-cli's doctor rules re-implemented both with weaker logic, so the tested rk-store versions are not what `doctor` runs.

## Evidence
- crates/rk-store/src/retention.rs:59 @ ce4ed1a: `looks_like_credential` (len >= 16, CREDENTIAL_PREFIXES, PEM `BEGIN ... PRIVATE KEY`, long mixed-case-digit run). Callers: only rk-store/tests/it/store.rs:523,526.
- crates/rk-store/src/conn.rs:209 @ ce4ed1a: `looks_like_network_filesystem` (UNC and `//?/UNC/`, explicitly not `//?/` local). Callers: only rk-store/tests/it/store.rs:190,193.
- crates/rk-cli/src/doctor/rules.rs:1334-1342 @ ce4ed1a: `credential_retained` checks only `["sk-ant-", "Bearer "]`.
- crates/rk-cli/src/doctor/rules.rs:1304-1311 @ ce4ed1a: `network_fs` flags any path starting `\\` or `//` plus `/net/`, `/mnt/net/`, `/Volumes/`. A Windows verbatim local path (`\\?\D:\...`, what `canonicalize` yields) matches `starts_with("\\\\")`, whereas rk-store's helper excludes it; `/Volumes/` also covers local macOS disks.
- Records: s7d-cli-and-migrate.md:242,3862-3863 (RT-45) build these rows "to the accepted record" and owe a register criterion; none mentions the unused rk-store helpers. Unchanged at 62dd3b8.

## Impact
`RK-D-CREDENTIAL-RETAINED` misses most credential shapes ADR-0105 clause 7 wants flagged (private keys, other prefixes, long tokens); `RK-D-NETWORK-FS` can raise a false error on a verbatim local path. The unit-tested logic is dead code.

## Suggested fix
Call `rk_store::retention::looks_like_credential` from `credential_retained` (scan every JSON string value) and `rk_store::conn::looks_like_network_filesystem` from `network_fs` (add the POSIX prefixes there if wanted), delete the local copies, and add doctor fixtures for a PEM key and a `\\?\C:\` path. Alternatively delete the rk-store helpers and test the rk-cli ones; do not keep both.
