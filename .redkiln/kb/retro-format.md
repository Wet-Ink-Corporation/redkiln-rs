## The lightweight note

`lightweight-retro`: *"Short what-went-well/what-to-change note"*, from the implementation report. The note has
two parts:

1. **What went well.**
2. **What to change.**

Its rationale: *"A one-shot note per small item; the structured form is reserved for projects and initiatives."*
It reads the implementation report and, where present, the review verdict. Its ceiling is rigor `recommended`, and
the family escalates above it.

## The forms above it

The raw catalog orders the learning ceremonies: *"`lightweight-retro` < `structured-retrospective` <
`blameless-postmortem`."* `structured-retrospective` is *"Set the stage, gather data, generate insights, decide,
close (e.g. 4Ls/starfish)"*, for initiatives and projects. The lightweight note does not run those phases.
