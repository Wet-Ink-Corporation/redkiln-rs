# Redkiln-RS

Redkiln-RS is a clean-break rewrite of redkiln as a single Rust binary, `redkiln`, that owns the whole loop: a deterministic kernel handles stage selection, gate evaluation, budgets, retry and replay, and dispatches one harness process per activity. The workspace is split into crates under `crates/` (`rk-types` and `rk-ports` at the core, `rk-kernel` for the workflow, `rk-store`, `rk-git` and `rk-containment` for infrastructure, the `rk-adapter-*` crates for the real harness, store and toolchains, and `rk-cli` as the binary), with dependencies pointing inward. The design lives in `references/2026-09-08-architecture-design.md`, the decisions in `references/adr/`, and the build order in `RUNBOOK.md`; where this README disagrees with those records, the records win. To build and check it, use the pinned toolchain from `rust-toolchain.toml` and run `cargo nextest run --workspace` for tests and `cargo clippy --workspace --all-targets` for lints; `AGENTS.md` lists the full gate.
